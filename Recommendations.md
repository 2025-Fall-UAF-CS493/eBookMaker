
A number of additional features could be added by interested developers to further assist in the St. Lawrence Island Yupik people's reclamation of their language and cultural heritage. A few helpful suggestions are listed below.

# Recommendations for Future Development
*Read pdfrx documentation (link in the README)
*Read pdfx documentation
*Expand TEI compliance for XML. XML is the supported data format that PDF files 
can be exported to create readable eBooks. TEI is an XML format https://www.tei-c.org/
*Conduct user testing of the eBookMaker software.
*Experience in Dart or similar programming languages is strongly recommended

## Useful Features to Add
*Be able to autoselect each line of text and merge individual characters in a PDF
*Add a tree data structure for the TEI tags
*Add a library file that holds different words from selections
*Add a settings file that allows users to configure app details
